# Security

If you find a way to get a destructive command or a credential read past the guard, please report it privately with the "Report a vulnerability" button in the Security tab. Don't open a public issue for it.

Send the exact command, which shell you used and what the guard returned. A test case in the same format as `tests/test_guard.py` helps a lot.

I maintain this alone in my free time, so I can't promise a response time. I'll answer as soon as I can and credit you in the fix commit if you want.

The gaps already listed in the README under "Known gaps" don't need a report.

Only the latest commit on `main` is supported.
